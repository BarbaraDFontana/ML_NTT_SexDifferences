# Scripts

This folder contains the scripts used throughout the machine learning workflow, including:

* Generation of individual behavioral labels based on consensus classifications provided by experienced researchers.
* Data preprocessing and preparation for machine learning analyses.
* Training and validation of machine learning models.
* Hyperparameter tuning and model optimization.
* Performance evaluation using multiple classification metrics.
* Model comparison and selection of the best-performing algorithm.
* Generation of confusion matrices, performance plots, and feature importance analyses.

The workflow was designed to ensure reproducible labeling, robust model validation, and objective model selection.
