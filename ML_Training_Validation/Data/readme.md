# Data

This folder contains the datasets used throughout the machine learning workflow.

* **Raw data:** Original behavioral observations prior to label assignment.
* **Consensus labels:** Behavioral labels generated through agreement between two experienced researchers.
* **Labeled data:** Datasets containing observations and their corresponding consensus-derived labels, used for machine learning model training and validation.

These datasets support the complete workflow, from label generation and data preprocessing to model training, validation, and performance evaluation.

## Important Note

The dataset used to train and validate the machine learning models was not used in the analysis of sex differences in zebrafish. An independent dataset was employed for the biological analyses to prevent data leakage and minimize potential bias, ensuring the independence of both the machine learning workflow and the downstream biological results.
