Data

This folder contains the raw and labeled datasets used in this project. Raw data include the original observations, while labeled data contain labels assigned from consensus information and are used for machine learning model training and validation.

**Important:** The dataset used to train and validate the machine learning models was not used in the analysis of sex differences in zebrafish. A separate, independent dataset was employed for the biological analyses to prevent data leakage and minimize potential biases arising from model development and evaluation.
